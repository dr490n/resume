简单的个人简历项目

  • 本项目是一个简单的个人简历网页展示项目，使用 Vue 2 + Element UI 构建，支持导出 PDF 和图片格式。
  • 请在弹窗中输入简历上求职者的电子邮箱地址以验证您是否有权限查看该简历。
  • 个人简历数据在回答正确电子邮件地址前完全加密，确保信息安全。
  • 完全静态页面，不需要后端服务！
